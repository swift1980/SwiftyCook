# SwiftCook
Recipe database. Vue.js front end with .Net api and mariadb docker

Functionality :
1. Searching of Recipes by name
2. Searching of Recipes by Ingredient or combination of Ingredients, option for all ingredients or some ingredients
3. UI - Different display page for Cocktails (CategoryId 1)
4. Cupboard - Track and store ingredients that user has in stock
5. Searching of Recipes by ingredients in cupboard
